# Spreadsheet automated sync

LitBuy Finds uses a **static JSON catalog** (`src/data/products.json`) baked into each Vercel deploy. New products cannot be written at runtime on serverless — they must be committed to git and rebuilt.

## Recommended architecture

| Layer | Role |
|-------|------|
| **GitHub Actions** (`spreadsheet-sync.yml`) | **Primary import** — weekly schedule + manual trigger. Runs full sync, regenerates manifests, commits to `main`, Vercel auto-deploys. |
| **Vercel Cron** (`/api/cron/spreadsheet-check`) | **Weekly dry-run check** — reports pending imports without modifying data. |
| **Local / manual** (`npm run spreadsheet:sync`) | On-demand import before pushing. |

### Why not Vercel Cron alone?

1. **No persistent filesystem** — serverless functions cannot commit `products.json` to your repo.
2. **Long runtime** — full import scans 8 tabs (~70–90s with rate-limit delays); manifest regen adds ~40s.
3. **Deploy required** — new `/find/[slug]` pages only exist after `next build`, which happens on git push to `main`.

## Commands

```bash
# Full automated sync (import + manifests + log)
npm run spreadsheet:sync

# Preview without writing files
npm run spreadsheet:sync -- --dry-run

# Import only (no manifest regen)
npm run merge:spreadsheet

# Regenerate manifests after manual import
npm run regenerate:catalog

# Dry-run check (Latest Finds + Trending tabs)
npm run spreadsheet:check
```

## GitHub Actions setup

Workflow: `.github/workflows/spreadsheet-sync.yml`

- **Schedule:** Every Monday, 08:00 UTC
- **Manual:** Actions → Spreadsheet sync → Run workflow

No extra secrets required — uses the default `GITHUB_TOKEN` for commits to `main`.

After a successful run with new products, Vercel deploys automatically from the push to `main`.

## Vercel Cron setup

`vercel.json` registers `/api/cron/spreadsheet-check` every Monday 09:00 UTC.

Requires `CRON_SECRET` in Vercel project env (same as existing AI cron). Vercel sends `Authorization: Bearer <CRON_SECRET>` automatically.

The endpoint returns JSON with `pendingImport` count and the last automated import log entry.

## Import log

## Safety guarantees

- **Append-only** — existing product IDs and rows are never modified or deleted
- **Duplicate detection** — canonical affiliate URL (query params stripped)
- **Validation** — invalid links, missing images, bad names, and social assets are skipped
- **No frontend changes** — same product page templates and SEO metadata

## After import

New products automatically appear on:

- Category pages (by `category_slug` from sheet tab)
- `/latest` and Latest Finds hubs (`latest-finds` tab)
- `/trending` (`trending-now` tab)
- Sitemap (`/find/[slug]` generated at build time)
- Search index (regenerated by `spreadsheet:sync`)

## Adjusting the schedule

Edit `.github/workflows/spreadsheet-sync.yml` cron expression if the sheet updates more or less often than weekly.
